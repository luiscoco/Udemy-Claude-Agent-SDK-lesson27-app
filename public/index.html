Documented evaluation order · reference

This is an explanatory reference. The SDK does not emit a public event for every internal rule check. Observe the actual events below.

1 · Hooks

Deny outright or pass onward. Hook allow does not bypass deny and ask rules.

2 · Deny rules

A matching scoped deny blocks the call, including in bypassPermissions.

3 · Ask rules

A matching ask routes to canUseTool. In dontAsk, prompting is denied.

4 · Permission mode

bypassPermissions and acceptEdits can resolve eligible operations. Plan gates writes.

5 · Allow rules

Matching rules and safe built-in checks can approve calls before the callback.

6 · canUseTool

The callback decides unresolved calls; dontAsk denies instead of prompting.
