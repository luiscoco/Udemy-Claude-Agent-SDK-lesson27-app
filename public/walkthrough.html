01

Documented pipeline versus observable evidence

The six-step diagram is reference guidance. Public events expose hooks, callback invocations, native results and completion, not every internal rule comparison. Reference stage labels describe the configured experiment and do not pretend to be internal SDK telemetry.

02

Ask is distinct from hook allow

A hook allow does not skip deny or ask rules. The ask experiment uses a bare Write ask rule and a programmed callback that approves only the bounded classroom output. It is not a human approval UI.

03

Bare versus scoped deny

A bare disallowedTools name removes the tool definition, preventing that attempt. Bash(rm *) keeps Bash available and blocks matching commands as written. It is not a universal detector of every command spelling. The host guard independently restricts this lab to one disposable target.

04

File rule details

Bare Write ask and allow entries are used here. For path-scoped rules governing built-in writes, current docs specify Edit(path), including Write and NotebookEdit. Do not assume Write(path) works the same way.

05

Modes and safe built-ins

acceptEdits auto-approves eligible file operations; default can approve safe reads or read-only shell commands without a callback. allowedTools is pre-approval, not a complete tool inventory or universal whitelist. This lab narrows available tools explicitly.

06

Warnings are partial diagnostics

The SDK can warn for bypass mode or bare allow entries. acceptEdits can skip the callback without that construction-time warning. Matching rules from settings may also affect execution without being visible to the warning check.

07

Plan and critical-path exceptions

Plan mode routes write operations for approval regardless of allow rules. Some user-interaction tools and recognized critical-path removals are not automatically approved. This application never tests critical-path removal, production pushes or unrelated shell operations.

08

Cost and isolation

Each real model query uses an SDK budget threshold of $0.25, not a prepaid cap. A fresh bounded workspace and exact operation guard constrain the demonstration; SDK permission settings alone are not an operating-system sandbox. Credentials and all teaching media remain outside Git.
