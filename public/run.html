Configure and run the app.

Install the SDK, configure your key and run the classroom comparisons.

Application labWhat you will learnHow to runArchitecture & workflowCode walkthrough
01

Prerequisites

Install Node.js 24 or later and Git for Windows if the SDK needs Git Bash. Use an Anthropic API account with credit and model access. Python is needed only to regenerate student HTML.

node --version
npm --version
02

Install and create your .env file

From presentations enter this application, install locked dependencies and preserve an existing .env. Enter your own model key privately. No GitHub token or Managed Agents resource IDs are required.

cd .\agent-sdk\lesson27-permission-pipeline
npm ci
if (!(Test-Path .env)) { Copy-Item .env.example .env }
notepad .env
03

Start the application

Keep the terminal open and use the printed URL. Experiments create and clean up fresh temporary classroom directories; your course source is not the agent workspace.

npm start
# http://127.0.0.1:3127
04

Predict hook, deny and ask outcomes

Choose a mode and predict execute or block. Run the experiment and inspect actual hook decisions, callback counts and file evidence. The bypass modes are bounded classroom demonstrations.

npm run sample:env -- hook-deny
npm run sample:env -- deny-bypass
npm run sample:env -- ask-bypass
05

Compare automatic approval and callback fallback

Compare Allow rule with Callback deny. Both use default mode, but the allow rule resolves Write before the callback. Callback deny reaches the host fallback and leaves the file absent.

npm run sample:env -- allow-rule
npm run sample:env -- callback-deny
06

Compare acceptEdits with dontAsk

acceptEdits approves the classroom Write without a callback. dontAsk denies an unresolved Write without a callback. Use PostToolUse and host file checks to distinguish their outcomes.

npm run sample:env -- accept-edits
npm run sample:env -- dont-ask
npm test

Your .env configuration

ANTHROPIC_API_KEY=your_api_key
CLAUDE_MODEL=claude-sonnet-4-6
PORT=3127
# Windows if needed: CLAUDE_CODE_GIT_BASH_PATH=C:/Program Files/Git/bin/bash.exe

Only your model key is required. Keep it local and restart after edits. Existing shell variables take precedence.

Troubleshooting

Use Node 24+, API credit and a supported model. Configure Git Bash on Windows if requested. If the port is occupied, use the printed existing-app URL or change PORT. A zero callback count does not by itself prove approval. Check native errors, completion and host file evidence. Warnings do not cover every shadowing configuration.
